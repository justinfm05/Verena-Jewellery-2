Circular icon-only button for nav bars and card overlays (wishlist heart, search, bag).

```jsx
<IconButton icon="heart" label="Save to wishlist" />
```

Renders a Lucide icon (via `data-lucide` + the Lucide UMD script, which must be loaded and `lucide.createIcons()` called). `variant="inverse"` for use on the dark-green surface.
