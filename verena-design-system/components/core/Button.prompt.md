Pill-shaped call-to-action button, used for add-to-cart, checkout, and primary nav actions.

```jsx
<Button variant="primary" size="m" onClick={addToCart}>Add to cart</Button>
```

Variants: `primary` (solid deep-green, gold text — main CTA), `secondary` (outlined, for secondary actions like "View details"), `ghost` (text-only, for tertiary/inline actions), `accent` (solid gold, use sparingly for a single standout action per screen). Sizes: `s`, `m`, `l`. Set `disabled` to dim to 40% opacity.
